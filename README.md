1. Contexto e Objetivos
Este caderno temático foi criado para explorar o tema Engenharia de Prompts com auxílio do NotebookLM. O objetivo é compreender como estruturar instruções eficazes para modelos de linguagem, identificar técnicas como zero-shot, few-shot e chain-of-thought, e aplicar esse conhecimento em contextos educacionais e profissionais.

3. Engenharia de Prompts e Cicatrizes
Prompts testados
Prompt 1 — Conceito básico:

"Explique o que é engenharia de prompts em linguagem simples para iniciantes."

Resultado: Resposta clara e objetiva. Boa para introdução.
Prompt 2 — Com contexto e papel:

"Você é um professor universitário. Explique engenharia de prompts para alunos do primeiro semestre de tecnologia, usando exemplos práticos."

Resultado: Resposta mais rica, com exemplos e analogias.
Prompt 3 — Chain of Thought:

"Pense passo a passo: quais são as diferenças entre zero-shot, one-shot e few-shot prompting? Explique cada um com um exemplo."

Resultado: Resposta bem estruturada e didática.
Dificuldades encontradas

Prompts muito curtos geraram respostas genéricas.
Sem definir o público-alvo, as respostas eram técnicas demais.
Adicionar "pense passo a passo" melhorou significativamente a qualidade.


4. Miniguia de Estudo
Resumo Estruturado
O que é Engenharia de Prompts?
É a prática de elaborar instruções claras e estratégicas para orientar modelos de IA a produzirem respostas mais precisas e úteis.
Principais técnicas:

Zero-shot: sem exemplos, apenas instrução direta
Few-shot: com exemplos para guiar o formato da resposta
Chain of Thought: solicita raciocínio passo a passo
Role Prompting: atribui um papel ao modelo
Divisão de Tarefa: divide problemas complexos em partes menores


Glossário
Prompt: Instrução dada ao modelo de IA.
Token: Unidade básica de texto processada pelo modelo.
Alucinação: Resposta incorreta gerada com aparente confiança.
Janela de contexto: Limite de tokens que o modelo processa por vez.
Few-shot: Técnica que usa exemplos no prompt.
Zero-shot: Técnica sem exemplos, só com instrução.
Chain of Thought: Raciocínio passo a passo induzido pelo prompt.

Prompts Reutilizáveis
1. "Explique [conceito] para [público], usando linguagem simples e exemplos práticos."

2. "Você é um especialista em [área]. Liste os [número] principais [itens] sobre [tema], em formato de tópicos."

3. "Pense passo a passo e explique a diferença entre [conceito A] e [conceito B], com um exemplo de cada."

4. "Resuma o texto a seguir em até [número] palavras, destacando os pontos principais: [texto]"

5. "Crie um glossário com os [número] termos mais importantes sobre [tema], com definições claras e objetivas."
